# Examples without nea_tools

SDK examples which can be run as is in neaSCAN console. 

### scan.py

Functionalities to create and edit instances of `ScanParameters` as well as to run scans.

### laser.py

Basic handling of lasers like selecting, starting emission and tuning.

### approach.py

Basic approaching and retracting of tip

### search_database.py

Perform a keyword search through projects and scans in neaSCOPE database.

### move_tip.py

Move tip to given coordinates with given speed.
